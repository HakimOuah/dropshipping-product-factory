# Google Ads Product Selection

## Shopping-first

Produit prioritaire Shopping si :

- requete produit claire ;
- produit visuel ;
- comparaison image/prix importante ;
- Google Shopping actif ;
- feed optimisable ;
- faible besoin d'education ;
- prix TTC compatible avec marge et CPC.

Livrable attendu :

| Champ | Exigence |
|---|---|
| Requete produit | une formulation d'achat claire |
| Shopping actif | captures ou notes SERP avec prix observes |
| Feed | attributs differenciants identifiables dans titre/image |
| Page | fiche produit rapide, reassurance proche CTA |
| Risque | guerre des prix ou commoditisation documentee |

## Search-first

Produit prioritaire Search si :

- requetes probleme/solution ;
- besoin de pedagogie ;
- besoin de comparaison ;
- panier suffisant ;
- objections fortes ;
- landing page persuasive utile.

Livrable attendu :

| Champ | Exigence |
|---|---|
| Requetes probleme | douleur/desir formule par le client |
| Intent | comparaison, solution, achat ou prix |
| Page | pedagogie, mecanisme, preuves, FAQ |
| CAC | panier assez haut pour financer clics plus chers |
| Risque | education trop longue ou claim trop risque documente |

## Both

Produit `Both` si une requete produit claire existe et si un angle probleme/desir permet de capter aussi des recherches Search.

Un produit `Both` doit avoir deux theses d'acquisition :

- Shopping : pourquoi l'image, le prix et le titre peuvent gagner le clic.
- Search : pourquoi la landing page cree plus de valeur qu'une fiche marketplace.

## Controle France

- Toujours regler Semrush, Keyword Planner ou tout outil keyword sur France.
- Croiser Semrush avec Google Trends France, Google Search et Google Shopping.
- Ne pas gonfler un cluster avec des requetes informationnelles ou hors sujet.
- Ne jamais utiliser United States pour valider un lancement France.
