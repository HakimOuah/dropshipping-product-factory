# Naming Conventions

## Produits

Dossier :

```text
products/YYYY-MM-DD-nom-produit
```

Regles :

- minuscules ;
- accents retires ;
- espaces remplaces par tirets ;
- mots inutiles retires ;
- garder un nom comprehensible.

## Boutiques

Dossier :

```text
boutiques/nom-projet
```

## Google Sheet

Feuille :

```text
recherche YYYY-MM-DD
recherche YYYY-MM-DD 2
```

## Fichiers Shopify

- SKUs : `MARQUE-PRODUIT-VARIANTE`.
- ALT image : decrire le produit et l'usage, sans bourrage SEO.
- Handles Shopify : minuscules, tirets, sans accents.
