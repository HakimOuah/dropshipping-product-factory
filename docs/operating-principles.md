# Operating Principles

## Mission

Construire une machine de test produit pour OH Ventures : peu de produits, analyses froides, decisions explicites, execution Shopify rapide apres validation.

## Regles par defaut

- France, francais, Google Ads, Shopify, SASU/OH Ventures.
- Les donnees business sont raisonnees HT, TVA au reel, IS.
- Le systeme cherche une these produit, pas un objet a copier.
- Le canal social peut inspirer, mais ne valide pas un produit Google-first.
- Les agents produisent des livrables reutilisables par l'agent suivant.
- Les limites d'acces aux outils doivent etre dites clairement.

## Definition d'une these produit

Pour un persona precis, vendre une offre comme une solution utile ou desirable, avec un angle qui permet de creer plus de valeur que les concurrents.

Formule douleur :

> Pour [persona] qui souffre de [probleme], vendre [produit/offre] comme [angle] afin de produire [benefice], contrairement aux concurrents qui [faiblesse].

Formule desir/high-ticket :

> Pour [persona] qui veut [desir/univers], vendre [produit/offre] comme [angle premium/pratique/esthetique] afin de creer [benefice], contrairement aux concurrents qui [faiblesse].

## Produits exclus en amont

Correcteur de posture generique, ceinture sudation/minceur, pistolet de massage generique, humidificateur LED generique, brosse anti-poils generique, lampe galaxie, gadget cuisine vu partout, miracle beaute/sante, accessoire telephone commoditise, mini imprimante, mini camera, gadget electronique sans promesse, produit dropshipping 2019, ferme, poulailler, elevage, materiel agricole, outillage industriel tres niche, pieces mecaniques obscures, B2B sans emotion d'achat, produit trop lourd, fragile, dangereux ou reglemente.

## Anti-doublon

Avant d'analyser :

1. Consulter le Google Sheet obligatoire.
2. Parcourir les feuilles `recherche YYYY-MM-DD`.
3. Comparer synonymes, accents, pluriel, anglais/francais, variantes et usages proches.
4. Exclure les produits deja recherches.
5. Reprendre uniquement si Hakim demande une mise a jour ou si la these est vraiment nouvelle.
