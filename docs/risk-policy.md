# Risk Policy

## Risques eliminatoires

- Claims sante, minceur, securite ou resultats non prouvables.
- Produit dangereux, tres reglemente, fragile, lourd ou a SAV disproportionne.
- Fournisseur note < 4,5/5 sans alternative credible.
- Livraison France trop lente pour une promesse claire.
- Produit deja analyse sans nouvelle these.
- Marge trop basse pour Google Ads.
- Produit qui ne tient que par une fausse urgence, de faux avis ou une fausse rarete.

## Conformite

Prioriser :

- Google Merchant Center ;
- DGCCRF ;
- RGPD/cookies ;
- informations de livraison ;
- politique de retour ;
- prix TTC transparents ;
- garanties reelles ;
- preuves sobres et verifiables.

## Comment ecrire un risque

Un risque doit etre concret :

- mauvais : "fournisseur a verifier" ;
- bon : "fournisseur unique, 170 commandes, note 4,6, livraison 18-24 jours, pas de backup EU trouve".
