# Human Validation Gates

## Gate 0 — Validation produit

Hakim valide ou refuse le produit apres lecture de `decision-brief.md`.

Avant Gate 0 :

- demande France verifiee ;
- AliExpress tente ;
- concurrents DTC analyses ;
- score et penalites appliques ;
- economie calculee ;
- these de differenciation ecrite.

Blocage dur : sans Gate 0 validee, aucun dossier boutique ne doit passer en Phase 1 active. Le script peut creer le dossier, mais `project-state.md` doit rester `bloque - Gate 0 manquante`.

## Gate 1 — Marque & charte

Hakim choisit :

- nom ;
- baseline ;
- palette ;
- typographie ;
- positionnement ;
- direction creative.

Le logo final reste manuel ou semi-manuel.

Blocage dur : sans Gate 1 validee, aucun contenu final ni build theme ne doit etre produit. Les propositions restent des options.

## Gate 2 — Structure

Hakim valide :

- sitemap ;
- sections ;
- wireframes ;
- logique CRO ;
- structure page produit ;
- parcours mobile-first.

Blocage dur : sans Gate 2 validee, pas de copy final, pas d'integration Shopify et pas de sections codees.

## Gate 3 — Site live

Hakim valide le rendu reel Shopify apres build. Aucun audit theorique ne remplace la verification sur site.

Blocage dur : sans Gate 3 validee, pas de lancement ads, pas de budget publicitaire et pas de go-live commercial.
