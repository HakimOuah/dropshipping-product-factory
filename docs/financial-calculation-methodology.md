# Financial Calculation Methodology

## Hypotheses par defaut

- Business : SASU / OH Ventures.
- Prix client : TTC.
- Analyse : HT, TVA au reel, IS.
- TVA France indicative : 20%.
- IS indicatif : 15% ou 25% selon tranche, a confirmer avec comptable.

## Calculs

| Ligne | Formule |
|---|---|
| CA HT | prix TTC / 1,20 |
| Cout produit HT | cout TTC / 1,20 si TVA recuperable, sinon cout TTC |
| Marge brute HT | CA HT - cout produit HT - cout livraison non refacture |
| Marge apres IS estimee | marge brute HT x (1 - taux IS) |
| CAC break-even HT | marge brute HT - frais variables - reserve SAV |
| Budget test | 3 a 5 fois le CAC cible ou minimum permettant 30-50 clics qualifies |

## Decision

Si le CAC break-even est trop bas pour les CPC Google observes, le produit est NO-GO ou doit etre repositionne : prix plus haut, bundle, cross-sell, meilleure offre, autre fournisseur.

## Seuil de respiration Google Ads

| Situation | Decision |
|---|---|
| CAC break-even < 25 EUR | NO-GO sauf panier tres recurrent ou CPC tres bas prouve |
| CAC break-even 25-50 EUR | MAYBE, Search risque, Shopping seulement si CPC bas |
| CAC break-even 50-80 EUR | Test possible si demande et CRO solides |
| CAC break-even > 80 EUR | Compatible Google Ads si fournisseur/conformite tiennent |

Le budget test doit permettre d'apprendre. Si le budget disponible ne permet pas au moins 30 a 50 clics qualifies ou 3 a 5 CAC cibles, le test doit etre reduit, reporte ou repositionne.
