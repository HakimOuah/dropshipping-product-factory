# Supplier Vetting Checklist

- [ ] AliExpress ouvert via Computer Use.
- [ ] URL fournisseur relevee.
- [ ] Prix produit releve.
- [ ] Prix livre ou frais estimes.
- [ ] Commandes relevees.
- [ ] Note produit >= 4,5/5.
- [ ] Notation vendeur credible, idealement >= 4,5/5.
- [ ] Delai France raisonnable.
- [ ] Pays d'expedition note.
- [ ] Expedie depuis Europe oui/non.
- [ ] Variantes pertinentes notees.
- [ ] Signaux de risque listes.
- [ ] Fournisseur backup cherche.
- [ ] Verdict risque : faible / moyen / fort.
- [ ] Condition de GO fournisseur ecrite si backup absent.
- [ ] Produit marque NO-GO ou MAYBE si fournisseur non exploitable.
- [ ] Prix livre transmis a `business-economics.md`.
