# Research Brief — Exemple boutique

## Synthese

Lumora Bain vend un miroir armoire LED antibuée comme une upgrade salle de bain premium, lumineuse et pratique. La boutique doit vendre le confort quotidien et la reassurance, pas seulement une fiche technique.

## Persona

| Element | Description |
|---|---|
| Client | couple ou foyer 30-55 ans |
| Situation | salle de bain fonctionnelle mais peu elegante |
| Declencheur | renovation legere, emménagement, remplacement miroir |
| Douleurs | buee, manque de rangement, mauvais eclairage |
| Desirs | salle de bain plus nette, premium, facile a vivre |
| Freins | casse livraison, installation, dimensions, qualite LED |

## Benchmark critique

| Type concurrent | Ce qu'il fait bien | Faiblesse exploitable |
|---|---|---|
| Specialiste miroir | choix et credibilite | page froide, peu emotionnelle |
| Specialiste salle de bain | univers coherent | livraison/retours peu visibles |
| Marketplace | prix bas, avis | faible confiance marque, tri difficile |

## Offre

- Produit principal : miroir armoire LED antibuée 80x60 cm.
- Prix cible : 249 EUR.
- Bonus : guide taille + guide installation.
- Garantie : casse transport.
- Cross-sell : kit microfibre entretien miroir.

## Economie

Scenario central : cout livre 91 EUR, prix TTC 249 EUR, CAC break-even 78 EUR. Si cout livre depasse 120 EUR, repositionnement ou NO-GO.

## Risques avant build

- Normes electriques et usage salle de bain.
- Politique casse transport.
- Images fournisseur exploitables.
- Gate 0 non validee dans cet exemple.
